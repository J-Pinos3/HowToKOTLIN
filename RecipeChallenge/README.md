# Meal Recipe App in Android
## Originally this was a UI challenge from KodaSchool, but I added the api and a db

### The technical features of this app are:
- MVVM Architecture
- Result Pattern
- Room Database
- Retrofit
- Use Of Generic Types
- NavigationComponents
- DiffUtil
- TheMealDB API
- Filtering And Delete In A Recycler View


### In this app the user can:
- Watch a Splash Screen
- Navigate Through a List Of "Recently Viewed" Meals Within Home
- Navigate Through a List Of Meals By Category Within Home
- Add Its Favorite Recipes To List In a Local Database
- Search Recipes By Typing Its Name Or By Chosing a Category
- Read All The Information Of The Given Recipe
